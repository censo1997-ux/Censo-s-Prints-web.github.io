# Censo Prints — Web

Web estática para GitHub Pages. Está preparada para empezar con el catálogo de elefante, lobo y serpiente.

## Archivos principales

- `index.html`: estructura y textos de la web.
- `styles.css`: colores, tamaños y diseño.
- `products.js`: **catálogo, descripciones y precios**. Es el archivo que tendrás que tocar normalmente para cambiar productos o precios.
- `script.js`: muestra automáticamente los productos del catálogo.

## Cambiar productos y precios

1. Abre `products.js` en GitHub.
2. Pulsa el lápiz (Edit).
3. Cambia el nombre, descripción o precios.
4. Pulsa **Commit changes**.

Los precios están inicialmente como “Consultar” porque todavía no se han definido.

## Publicar con GitHub Pages

En el repositorio, abre **Settings → Pages**. En **Build and deployment**, selecciona **Deploy from a branch**, elige la rama `main` y la carpeta `/(root)`, y guarda. GitHub mostrará la dirección pública cuando termine de publicar.

## Pendiente de configurar

- Fotografías reales de las figuras.
- Precios definitivos BASIC y PREMIUM.
- Canal de contacto/pedidos (por ejemplo, WhatsApp o correo).
- Información de envíos, plazos, pagos y devoluciones antes de aceptar pedidos.

La web no procesa pagos ni recoge datos personales por ahora.
